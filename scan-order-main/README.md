# Scan Order

Build a professional, modern, mobile-responsive Aganix QR Hotel Ordering System using React, TypeScript, Vite, and Tailwind CSS.

Features:

Customer menu accessed by scanning table QR codes.

Food categories, images, prices, cart, and checkout.

Online payment demo and pay-at-counter option.

Admin login and dashboard to receive orders, update order status, manage food items, prices, tables, and downloadable QR codes.

Premium UI, Indian rupee pricing, sample hotel data, and responsive design.

Use mock data and localStorage; no paid APIs or backend required.

Organize code into reusable components and folders.

Include README with setup instructions.

Ensure the customer ordering flow and admin demo work correctly.
